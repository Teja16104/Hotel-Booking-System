# Hotel Booking System

A console-based Hotel Booking System developed using Java and nested switch statements.

## Features
- AC and Non-AC room categories
- Multiple room types with different prices
- Book multiple rooms
- Calculate AC and Non-AC costs separately
- Generate the final hotel bill

## Technologies Used
- Java
- Scanner class
- Switch statements
- Do-while loops

## Concepts Used
- Nested switch statements
- Do-while loops
- Variables and data types
- User input handling

## How to Run
1. Download `HotelBooking.java`.
2. Open it in Eclipse or any Java IDE.
3. Run the program.
4. Enter the room category and room type.
5. Continue booking rooms and view the final bill.
